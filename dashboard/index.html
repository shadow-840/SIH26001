Welcome to TerraSentinel.

SIH26001: AI-Based Landslide Early Warning System for the North Eastern Region.

Predict. Warn. Protect.

TerraSentinel bridges the gap between complex geotechnical physics and actionable early warnings. Using real-time telemetry and infinite slope analysis, we protect vulnerable communities across the NER.

Backend Architecture

Powered by FastAPI, processing parallel telemetry from Open-Meteo and Open-Elevation. Evaluates Antecedent Moisture and the Mohr-Coulomb failure criteria.

Frontend Experience

Interactive Leaflet mapping with Google Maps Satellite Hybrid integration. Features real-time state synchronization and adaptive risk rendering.
